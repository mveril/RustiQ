# RustiQ Core

RustiQ Core is the reusable scientific library behind [RustiQ](https://github.com/mveril/RustiQ).
It explores how Rust's strong typing, memory safety, and modularity can support
quantum chemistry software, alongside numerical validation and performance.

The library provides molecular and basis data, scientific configuration,
calculation execution, and persistence. Runfile parsing and terminal output
belong to the RustiQ application. The Cargo package is `rustiq-chem-core`;
its Rust import name is `rustiq_core`.

RustiQ is experimental. Independently validate results against established
quantum chemistry packages before using them for research conclusions.
